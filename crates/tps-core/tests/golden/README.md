`library.tdb` was made by Tau Alpha's `tools/tau_library.py build <tree> --playlists` (the reference builder of the TAU library format, run 2026-11-11) from the tree that `tests/golden.rs` creates. The test builds the same tree with the plugin's rebuild and compares what the two indexes say (every title, name, path, count and order), not the raw bytes: the two builders share a string in the pool in slightly different cases (the pool of tau_library.py is keyed by text and encoding, Omega's by bytes), which the player does not see.
